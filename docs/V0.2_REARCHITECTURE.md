# V0.2 Re-architecture — reverse-engineering the Cute Sheep reference system

Test case: `patron.stl` (Cute Sheep doll, 79.0×71.3×99.1 mm) → reference product
`master_base + box_l + box_r` vs our platform output `OUTPUT/pourbox_patron`.
Measured with `scratch/diag_measure.py` + `scratch/diag_render.py` (sections,
ray scans, orthographic renders in `scratch/diag/`).

## 1. What the reference system actually builds (measured)

| file | geometry |
| --- | --- |
| `patron.stl` | the doll (input shape / casting preview) |
| `master_base.stl` | doll **with a contoured plate fused underneath**: plate 116.4×109.2 mm ≈ doll XY shadow + **~18.5 mm margin**, ~2.9 mm thick, solid, doll sits on it. One file = master + base. |
| `box_l` / `box_r` | two half **shells, split ⊥ Y**. Vertical span = **plate top → doll top + 10.4 mm**: the bottom rim **seats on the plate** (z −48.3 vs plate top −48.4; jacket bbox 120.5 ≈ plate + 2×2 mm wall wrap), the top is an **open crown** (no cap, no bore) whose opening follows the doll's shadow + gap (~91×83 mm — the "ellipse" opening). Walls hug the doll at min **~6 mm** (the doll's widest slices), boxier elsewhere (p50 ~20 mm), ~4.8 mm thick. Small stepped tongue where the halves meet; 2 small vent holes in the walls. |

Silicone pours through the open crown into the basin between doll and jacket;
the cured glove = cavity − doll. Product = exactly 3 printed files.

## 2. What our V0.1.1 built on the same input (measured)

| file | geometry | verdict |
| --- | --- | --- |
| `master.stl` | hollowed doll only, **no base** | base missing (separate part instead) |
| `base_plate.stl` | separate slab 91.1×83.8×8 mm under the master (margin ~6 mm) | too small, not fused, socket instead of seat |
| `jacket_A/B.stl` | closed bowl with a 6 mm **crown cap + Ø28 bore**, plus a **7 mm collar ring in the split plane dilated 10 mm beyond the jacket** (z −71.4…+73.6 vs master −48.4…+50.6) | ✗ the collar is the doll's full mid-height silhouette → it reaches **23 mm below the plate** and 23 mm above the head — the floating "frame" that eats support material and cost; ✗ top closed with a straw-sized bore instead of an open basin |

## 3. Root causes in code (`src/engine/split.ts` V0.1.1)

1. **Clip flange built as an in-plane ring**: `aFlangeCS = outerFill.offset(10) − innerFill`
   extruded ±7 mm along the pull axis (split.ts:157–168). Dilating the doll's
   *vertical* silhouette by 10 mm in the split plane pushes the ring 23 mm past
   the master's lowest/highest points → the hanging frame. The flange belonged
   at the jacket's bottom rim (on the plate), not around the mid-height silhouette.
2. **Crown kept from the old funnel architecture**: `frame.crown = top + 6` with a
   closed cap and a Ø28 `crownBoreSolid` (ports.ts + split.ts:181–188) instead of
   trimming the jacket **open** at the crown plane.
3. **Plate as a separate socketed part** (split.ts:207–237) instead of fused
   under the master with the jacket rim seating on it.
4. **Cavity = 3D dilation of the doll** (`S = master ⊕ gap`) instead of the
   commercial rule **cavity = doll's XY shadow ⊕ gap** — that's why the gap read
   right (p90 = 8.00) while the shape read wrong: the reference hugs only at the
   doll's widest slices and is boxy elsewhere.

## 4. V0.2 construction (parametric reproduction of the reference)

Frame: `vert` = stable-base axis, `pull` = quiet-line ranked axis, `base` = doll
min on vert, `crown = base + dollHeight + 10` (ref freeboard 10.4).

```
shadow      = union of the doll's XY slices (footprint blob)
cavityCS    = shadow ⊕ gap                    // hugs at the widest slices only
wallCS      = cavityCS ⊕ wall                  // 5 mm ring
plateCS     = shadow ⊕ plateMargin (18 mm)     // ≈ reference margin 18.5

jacket      = (vertPrism(wallCS, plateTop→crown) ∪ vertPrism(plateCS−0.3, plateTop→plateTop+3))
              − vertPrism(cavityCS, plateTop→crown)        // open crown, no cap
split A/B   = ±pull at mid; A carries a 2 mm tongue (cavityCS ⊕0→⊕2, y mid−2→mid),
              B a matching groove (⊕−0.2→⊕2.4, y mid−2.4→mid)
vents       = 1 per half: Ø2.5 bore along the pull axis at that half's highest
              master point (z = masterTop + gap + 1 → clears the master everywhere)
plate       = vertPrism(plateCS, base−4 → base)
master_base = hollow(doll, 3 mm shell) ∪ plate   // fused, like patron_base
glove       = vertPrism(cavityCS, plateTop→crown) − doll  // silicone fill preview
```

Consequences (all match the reference): jacket bottom sits on the plate (nothing
below plate top), walls are vertical → support-free printing, open crown =
91×83 mm basin opening at gap 6, silicone ≈ reference volume, clips grip the two
5 mm walls across the seam. `S`/`O` level-set jackets and the collar flanges are
gone; the SDF grid now only feeds contours, vents and gates.

## 5. Verification harness

- `scripts/smoke_v02.ts` — headless full pipeline on `patron.stl`, writes the
  package (OUTPUT/pourbox_patron_v02/), prints every gate + dimension.
- `scratch/verify_v02.py` — measures the new output against the reference and
  renders side-by-side views (`scratch/diag/v02_*.png`).
- Regression gates in `gates.ts`: **"Jacket seats on the plate"** (nothing
  below plate top — the V0.1 regression gate), "Open crown above the master",
  fill reachability seeded from the crown plane, extraction sim vs glove +
  master.
