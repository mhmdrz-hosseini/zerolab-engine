## What was implemented

### Intent and mold-family selection

- The UI, worker, CLI, and planner now pass casting intent: source role, required surfaces, requested family, signed backing normal, and multi-body handling.
- Unknown intent, tooling input, negative molds, and unsupported vessel-like input produce `review_required`; the generator must not publish a generic jacket for them.
- A `front_only` request builds only an `open_face_relief` tray. If tray construction fails, it returns a rejection instead of silently falling back to a full 3D jacket.
- The signed backing is canonicalized into the mold frame: backing down, detail up, and build plate on the printer bed. Source-to-mold and inverse transforms are exported in `project.json`.
- Full 3D packages use the approved backing to establish the vertical frame, then prohibit a split along that backing axis.

### Open-face relief construction

- The tray wall is a continuous contour ring, separate from the tray base/master, open at the top, and has a recorded fill level distinct from its freeboard.
- The planner performs exact rigid/silicone intersections between tray wall and master/base, and checks measurable bed contact for both printable pieces.
- Silicone quantity is calculated from the intended filled region; additional wall freeboard does not falsely increase the mixing quantity.
- Through-holes are retained as silicone posts when their geometry supports the tray strategy. Re-entrant cases must remain review/reject outcomes.

### Full-3D fit and material correction

- The planner reconciles tiny CSG crossings between silicone skin and the rigid package before export. It rejects a material-sized correction rather than hiding it.
- The former artificial base foot was replaced in `src/engine/split.ts`. The old code extruded a constant source slice from `base` to `base + 0.31 mm`; on a taper it occupied space that should have remained silicone. The new code joins the plate using only the master’s real lower material band. This directly targets the measured `Körper` silicone/master-base collision.
- Material reporting uses the correct equivalence: `1 cm³ = 1 mL`.

### Output integrity and evidence

- The export path cleans meshes and writes a serialized-STL audit into every `project.json`.
- `scripts/v3/run-required.ps1` records command lines, hashes, source/profile/contract fingerprints, exported STL hashes, and a minimal generation verdict.
- `scripts/v3/independent_audit.py` separately reimports the final files with Python/trimesh/manifold and checks basic mesh properties, assembly intersections, volume claims, transforms, bed contact, and the source-to-master surface distance.
- The independent audit deliberately does **not** promote a result to `digital_verified`; protected detail, hole topology, seal/clip fit, visual inspection, slicer checks, and physical qualification remain separate evidence.

## Remaining blocker — do not waive it

`Körper` output has a valid closed surface and rebuilds in the kernel, but its serialized silicone preview has **one pinched edge**. The final audit therefore returns `suspect`, not `valid`. The acceptance contract explicitly says:

```json
"suspectMeshCountsAsVerified": false
```

The pinched edge reported in the 50 mm result is near:

```text
[7.852622, -2.016212, 34.493404]
[7.736453, -2.343212, 34.458569]
```

It is high on the body, so it is unrelated to the corrected base-foot overlap.

A focused experiment was run on the actual exported skin with `scratch/v3/rescue-skin.ts`:

| Kernel simplification tolerance | Final serialized verdict | Pinched edges |
| ---: | --- | ---: |
| exact / `0` / `0.001 mm` | suspect | 1 |
| `0.005 mm` | valid | 0 |
| `0.01 mm` | valid | 0 |
| `0.05 mm` | valid | 0 |

This shows that a bounded repair is technically possible at 0.005 mm, well below the absolute 0.05 mm cap. It is **not yet certification evidence**, because the contract also requires the repair bound to be no more than one tenth of the measured finest protected feature and to record that measurement. Do not simply redefine a `suspect` mesh as acceptable.
